# Demo script

## Current M0 demonstration

1. Start with `npm ci` and `npm run dev`.
2. Open Studio, confirm the foundation label and live local API status.
3. Visit Projects, Assets and AI Models; show the milestone labels and disabled controls.
4. Change appearance in Settings and refresh to confirm persistence.
5. Open the build plan to see the next scene/schema milestone.

There is no rendered scene or AI/demo generator in this release. Do not present the foundation as the specification's completed two-minute demo.

## Full demo target (M8)

Follow `implement.md` section 21: configure/test/select a provider, generate a dancing robot scene, play/inspect, refine through a validated patch, undo/redo, save/reopen and export. If no key is available, use M4's clearly labeled local deterministic demo mode. A real provider failure must never be presented as success.
